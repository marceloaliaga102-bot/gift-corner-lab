# 🎁 Gift Corner Lab - Boutique Física & Digital

Una boutique interactiva y moderna creada con React 19, TypeScript, Tailwind CSS y Lucide Icons. Diseñada por Marcelo Aliaga & Angely.

## ✨ Características Principales

- ⚡ **Productos Virtuales:** Cuponeras digitales 3D, páginas conmemorativas, stickers y filtros descargables al instante.
- 📦 **Productos Físicos:** Lámparas acrílicas Spotify, cajas explosivas, botón de pánico "Miau" y regalos artesanales con coordinación de recogida en puntos de referencia.
- 💬 **Integración WhatsApp:** Redirección automática a WhatsApp con mensaje formateado (`+51 921 617 882`).
- 🔐 **Autenticación Unificada Discreta:** Inicio de sesión único para usuarios y creador (`marceloaliaga102@gmail.com` / `marcelo2025`).
- 🛠️ **Panel Admin:** Publicación de nuevos productos, carga de archivos HTML/ZIP, gestión de videos y puntos de recogida.
- 📦 **Exportación Directa:** Descarga del código fuente completo en `.zip` directamente desde la tienda.

---

## 🚀 Ejecución Local

1. Instalar dependencias:
   ```bash
   npm install --legacy-peer-deps
   ```

2. Iniciar servidor de desarrollo:
   ```bash
   npm run dev
   ```

3. Construir para producción:
   ```bash
   npm run build
   ```

## 🌐 Despliegue en Internet (Vercel / Netlify / Cloud Run)

### Vercel (Recomendado)
1. Sube tu proyecto o carpeta a GitHub.
2. Ingresa a [vercel.com](https://vercel.com) y conecta tu repositorio.
3. Vercel detectará Vite automáticamente. Haz clic en **Deploy**.

### Netlify
1. Ingresa a [netlify.com](https://netlify.com).
2. Arrastra la carpeta `dist` (generada con `npm run build`) o conecta GitHub.
